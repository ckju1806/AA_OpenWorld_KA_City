# Steuerung (Tastatur + Maus) – v0.2

Alle Tasten außer Esc sind unter **Einstellungen → Tastenbelegung** frei belegbar (Konflikte werden angezeigt; gleiche Taste
nur für Aktionen aus verschiedenen Situationen erlaubt, z. B. Springen/Handbremse). Unten steht die Standardbelegung
(physische Tasten, d. h. unabhängig vom Tastaturlayout; `^` = Taste links neben der 1).

## Zu Fuß
| Taste | Aktion |
|---|---|
| W A S D (oder Pfeiltasten) | Bewegen (relativ zur Kamera) |
| Maus | Umsehen |
| Umschalt (Shift) | Rennen |
| Leertaste | Springen |
| E | Interagieren: mit Auftraggebern sprechen, Sendung abgeben, **an Haltestellen in Bahn/Bus einsteigen** (3 € Fahrschein), Dialog überspringen |
| F | In ein nahes Fahrzeug einsteigen (markierte fremde Fahrzeuge werden übernommen – das kann die Polizei interessieren) |

## Im Fahrzeug
| Taste | Aktion |
|---|---|
| W | Gas |
| S | Bremsen, im Stand rückwärts |
| A / D | Lenken (geschwindigkeitsabhängig) |
| Leertaste | Handbremse |
| H | Hupe (Passanten und Tiere erschrecken) |
| L | Licht an/aus |
| C | Nach hinten schauen (gedrückt halten) |
| R | Fahrzeug bergen (nur wenn umgekippt oder festgefahren und langsam; kurze Sperrzeit; Fahndung bleibt bestehen) |
| F | Aussteigen (nur bei niedriger Geschwindigkeit und freiem Ausstieg) |

## Mitfahren im ÖPNV (Stadtbahn, Bus)
| Taste | Aktion |
|---|---|
| E | An der Haltestelle einsteigen, wenn ein Fahrzeug hält |
| E oder F | Während der Fahrt: Haltewunsch – Ausstieg an der nächsten Haltestelle |
| Maus | Umsehen (Kamera folgt dem Zug) |

## Allgemein
| Taste | Aktion |
|---|---|
| M | Vollkarte öffnen/schließen (pausiert) |
| J | Auftragsliste: Kampagne nach Handlungssträngen, Status, Wegpunkt setzen, Aufträge wiederholen, Jobs annehmen, Ruf |
| ^ | Cheat-Konsole (eigene deutsche Codes, z. B. `GELDREGEN`; `HILFE` listet alle Codes, `AKTIV` die eingeschalteten). Codes lassen sich auch direkt im Spiel tippen |
| Esc | Pausenmenü (Fortsetzen, Speichern, Einstellungen, Steuerung, Hauptmenü, Beenden); schließt Karte/Untermenüs |
| F3 | Entwickleranzeige (FPS, Renderstatistik, Objektzahlen, Position, Fahndung, Missionsschritt) |
| Eingabe (Enter) | Nach einem Fehlschlag: Auftrag erneut versuchen |
| Rücktaste | Nach einem Fehlschlag: Auftrag abbrechen |

Mausempfindlichkeit, Y-Invertierung, Sichtfeld, Kamera-Autozentrierung, Kamerawackeln, Untertitel, HUD-Deckkraft und
Farbfehlsicht-Filter sind in den Einstellungen änderbar. Gamepads werden in dieser Version nicht unterstützt.
